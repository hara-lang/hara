# Inspect an audio graph

This complete Showcase project renders the portable Supersonic graph as an
ordinary Hara value. It does not request `:audio/playback`, start a provider or
create Web Audio resources.

The graph records:

- typed nodes and ports;
- bounded number, choice and boolean controls;
- explicit control and audio connections; and
- the authority boundary between silent graph preparation and user-authorized
  browser playback.

Use the State and Source tabs to inspect the exact graph fixture and HAL adapter.
