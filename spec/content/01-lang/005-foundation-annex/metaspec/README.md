# Hara Foundation annex meta-specification

Status: **draft**

[`foundation-annex-metaspec.edn`](foundation-annex-metaspec.edn) defines the
required shape of the public `std.foundation.*` library annex.

A conforming annex declares each public library namespace, public Vars,
implementation classification, native and protocol dependencies, automatic
aliases, capability requirements, private helper namespaces, and evidence.
