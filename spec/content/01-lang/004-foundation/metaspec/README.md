# Hara Foundation meta-specification

Status: **draft**

[`foundation-metaspec.edn`](foundation-metaspec.edn) defines the required
shape of the root `std.foundation` specification.

A conforming Foundation document declares bootstrap referral, namespace
configuration, public surface groups, ownership classification, metadata,
errors, and conformance evidence. A fresh-context public-Var inventory must
match the declared groups before candidate promotion.
