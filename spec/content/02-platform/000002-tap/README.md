# 000002 — Federated taps

This specification defines the Git-authoritative trust and discovery model
shared by Hara identity, package, asset, publication, distribution, and mirror
protocols.

- [`metaspec/hal-tap-protocol-metaspec.edn`](metaspec/hal-tap-protocol-metaspec.edn)
  defines the reusable protocol document model.
- [`draft/hara-tap.edn`](draft/hara-tap.edn) is normative.
- [`draft/README.md`](draft/README.md) is the informative rendering.
