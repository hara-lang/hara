# 000001 — CLI applications

This specification separates the reusable CLI document model from the concrete
Hara command-line application:

- [`metaspec/`](metaspec/) defines valid CLI application specifications,
  including their entities, references, laws, checkers, and generation process.
- [`draft/`](draft/) defines Hara's public CLI routes, compatibility aliases,
  options, closed handler registry, structured outcomes, and shared
  conformance corpora.

The EDN documents are normative. The adjacent Markdown files explain their
scope and navigation.
