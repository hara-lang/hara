#+STARTUP: showall

* TypeScript User Directory

This example shows how to use native Hara =def.make= to generate both runtime
JavaScript and TypeScript declaration files.

- =main.hal= is the runtime =:js= module
- =types.hal= is the typed xtalk surface
- =build.hal= uses the TypeScript artifact helper to create =.d.ts= declarations

* Generated build tree

Running =(make/build-all PROJECT)= writes:

- =.build/.gitignore=
- =.build/Makefile=
- =.build/package.json=
- =.build/src/index.js=
- =.build/src/index.d.ts=

The declaration artifact is created by the TypeScript artifact helper in
=build.hal= and written beside the runtime JS file.

*** Validate the native build definition

#+BEGIN_SRC bash :results output silent :eval no
../hara-native/core/rust/target/release/hara-native test --project . \
  --file test/play/ts_000_user_directory/build_test.hal
#+END_SRC

*** Inspect the source definitions

#+BEGIN_SRC bash :results output silent :eval no
rg -n "def\.js|defn\.js|def\.xt|defn\.xt" main.hal types.hal
#+END_SRC
