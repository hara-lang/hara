* Go user directory example

This example shows a minimal native Hara =def.make= Go project. The source
logic lives in =main.hal= using =l/script :go=. Running the build writes a small Go library
project into =.build/= with:

- =.gitignore=
- =Makefile=
- =go.mod=
- =user_directory.go=

The generated =user_directory.go= is a normal Go source file with an explicit
=package userdirectory= header, so the emitted project can be built with:

#+begin_src bash
../hara-native/core/rust/target/release/hara-native test --project . \
  --file test/play/go_000_user_directory/build_test.hal
#+end_src
